# Calculate Hidden Power stats

Calculates the type & base power of Hidden Power for the Pokémon in box 1, slot
1, and then prints that value in box 1's name. For instance, if your Pokémon has
a rock type Hidden Power with a base power of 65, this script will rename box 1
to `RCK 65`.

This is a large & overwrought script, and I don't recommend using it as this
information can just as easily be gotten with the `ReadIvs` Metagross & an
online calculator. I mostly created it for fun.

The type abbreviations used by this script are:
