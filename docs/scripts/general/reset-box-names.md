# Reset box names

Renames all of the PC boxes. Depending on the marking used, it will either reset
all boxes to their original names (e.g. `BOX1`), or set all of their names to
`AAAAAAAA` (which can make entering box codes a little bit quicker). It can also
be used to reset wallpapers back to their defaults, if so desired.
